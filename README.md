# ilovespectraltheorem.github.io

My personal page: <https://ilovespectraltheorem.github.io>

Plain HTML, served directly by GitHub Pages (from the `main` branch, no build step).

- `index.html`: the page
- `playground.html` + `la2d.js`: the linear algebra playground
- `style.css`: styles

Edit, then `git commit -am "…" && git push`. The site updates in about a minute.

The earlier Hugo version of this site is kept under the Git tag `hugo-site-backup`.
